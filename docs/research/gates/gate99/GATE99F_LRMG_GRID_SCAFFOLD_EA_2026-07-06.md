## Indicator Inputs

The EA reads:

- `LimniLRMGMA`, buffer `0`: LRMG David State value
- `LimniLRMGStoch`, buffer `0`: LRMG Stoch value

Both handles are created on fixed `PERIOD_M1` with the same
`ScaleLookbackDays`. The indicators themselves remain non-timeframe-dependent
internally because they source fixed M1 and completed-day LRMG `q`.

## LRMG Grid Spacing

Grid adds use LRMG units, not blunt ADR units.

The EA computes current-day `q_effective` internally from completed prior M1
days using the same movement-radius helper:

```text
grid_step_price = q_effective * GridSpacingLrmgUnits
```

Default `GridSpacingLrmgUnits=1.0`, so one adverse LRMG movement quantum creates
the next grid add.

## Variant A

Enum:

`VARIANT_A_ONE_SHOT_PER_STATE`

Description:

```text
Red LRMG David State:
  first Stoch cross from >= 90 to < 90 opens one sell grid
  repeats are ignored while state remains red

Green LRMG David State:
  first Stoch cross from <= 10 to > 10 opens one buy grid
  repeats are ignored while state remains green
```

This is the cleaner risk-first hypothesis.

## Variant B

Enum:

`VARIANT_B_CONDITION_WHILE_STATE_VALID`

Description:

```text
Red LRMG David State + Stoch < 90 allows a sell grid
Green LRMG David State + Stoch > 10 allows a buy grid
```

The EA still blocks same-side re-entry while a same-side grid is open. Opposite
valid signals close the current grid and open the new side if the close
succeeds. This keeps the scaffold testable without adding TP/SL.

This is the higher-harvest / higher-overfeed hypothesis.

## Lifecycle

- Chart-symbol only.
- Tester-only by default.
- One managed grid at a time per chart symbol.
- No SL/TP.
- Adverse grid adds continue until `GridCap`.
- Opposite valid scaffold signal closes the current grid and reverses.
- Terminal open grid is marked at deinit.

CSV receipts are written under MT5 Common Files:

`LimniLRMGGridScaffoldEA/`

Receipts:

- `*_events.csv`
- `*_summary.csv`

The summary reports entries, grid adds, max fill count, closed Q, terminal
marked Q, ignored signal counters, and open-grid MFE/MAE in Q units.
